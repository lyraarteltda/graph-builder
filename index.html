Estrutura

Como ligar

  • Arraste do ponto direito de uma peça até o ponto esquerdo de outra.
  • Clique numa peça para escrever as instruções dela.
  • Clique num fio para cortá-lo. Del apaga a peça selecionada.
  • Fio de uma peça para a Memória = ela escreve. Fio da Memória para uma peça = ela consulta.
  • Ctrl+D duplica a peça selecionada, com instruções e barra.
  • Arraste o fundo para andar · scroll para zoom · Ctrl+Z desfaz.

O quadro está vazio.

Escreva o objetivo na coluna da direita, depois pendure trabalhadores, supervisores e uma entrega.

O grafo

O objetivo orienta todas as peças ao mesmo tempo — ele abre o texto exportado e entra no prompt de sistema de cada agente. É a única coisa que a IA lê antes de qualquer instrução.

Clique numa peça do quadro para escrever as instruções dela.

Trabalhador

Preencher rápido — a barra

Cada botão escreve um critério que um estranho consegue julgar sozinho, só com o artefato na mão. Clique de novo para tirar.

Um exemplar real e alcançável, que o crítico consiga abrir e colocar na mesma situação. "As melhores do mercado" não serve — ninguém consegue julgar contra isso.

Se o supervisor reprovar, o trabalhador refaz. Depois deste teto, entrega o melhor que tiver com as ressalvas anotadas.

Caminhos — a condição de cada fio

Escreva quando seguir por cada fio. A IA segue um só: o primeiro cuja condição bater. Deixe o último como "em qualquer outro caso" para nunca travar.

Preencher rápido — esquema pronto

Cada coisa a que alguém vai querer se referir depois vira um item, com seus campos.

Escreva primeiro as perguntas que você vai querer fazer ("o que cai se esta fonte cair?") — cada pergunta pede um tipo de ligação.

Conferidas antes de qualquer Entrega. Se uma falhar, a Entrega diz o que ficou em aberto.
